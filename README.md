# vrtx-sentinel-azure-final

Proyecto independiente de migracion completa de VRTX-SENTINEL a Azure + Copilot Security.

## Inicio rapido
1. Crear entorno virtual.
2. Instalar dependencias con `pip install -r requirements.txt`.
3. Copiar `local.settings.json.example` a `local.settings.json`.
4. Ejecutar tests con `pytest`.

La documentacion principal esta en `docs/README_AZURE.md`.
